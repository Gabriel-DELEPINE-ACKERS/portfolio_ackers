SAE2.04 - Projet Intégratif - Travaux pratiques

Dans le cadre de la SAE 2.04 - Projet Intégratif, j’ai participé au développement d’une chaîne complète de collecte et de visualisation de données de température.
Le projet consistait à concevoir un capteur électronique, récupérer les données avec Python, les stocker dans une base PostgreSQL puis les afficher en temps réel avec Grafana sur un serveur OpenStack.

Chaine de mesure de température

Création des bases des données

Objectifs

  • Concevoir une chaîne de mesure de température
  • Développer un programme Python de récupération et traitement des données
  • Configurer un serveur Linux sous OpenStack
  • Installer PostgreSQL et Grafana
  • Visualiser les données en temps réel
  • Travailler en autonomie avec GitLab et gestion de projet

Auto-réflexion

Cette SAE m'a permis de travailler sur un projet complet combinant électronique, développement Python, administration système et visualisation de données.

J'ai particulièrement progressé dans l'intégration de plusieurs technologies au sein d'une même infrastructure ainsi que dans l'organisation d'un projet technique sur plusieurs semaines.

Compétences acquises

  • Déploiement et administration d'un serveur Linux
  • Utilisation d'OpenStack pour la gestion de machines virtuelles
  • Gestion d'une base de données PostgreSQL avec Python
  • Développement Python orienté acquisition de données
  • Travail en équipe et gestion de projet avec Gantt
  • Visualisation des données en temps réel avec Grafana avec la mise en place de tableaux de bord personnalisés
